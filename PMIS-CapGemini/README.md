# PMIS CapGemini - Calculator

A simple Java 17 Maven project with JUnit 5 tests.

## Project structure

```text
PMIS-CapGemini/
├── pom.xml
├── src/
│   ├── main/
│   │   └── java/
│   │       └── Calculator.java
│   └── test/
│       └── java/
│           └── CalculatorTest.java
└── target/                 # generated by Maven when you run tests
```

## Run the tests

From this directory, run:

```bash
mvn test
```

Requirements: JDK 17+ and Maven installed.
